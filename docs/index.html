Methodology: Cross-Evaluation

1. Load Benchmark

Fetch original questions from Hugging Face datasets (GSM8K, MMLU, etc.)

2. Generate Variants

Reword each question using a dedicated 3B LLM; validate semantic similarity (≥0.60) with all-MiniLM-L6-v2

3. Evaluate Both

Run target model on original and variant questions; compare answers to ground truth

4. Compute Drop

Accuracy drop >30% → sample flagged as potentially contaminated

Contamination Index = (Original Accuracy − Variant Accuracy) × 100

Why Cross-Evaluation Works

A contaminated model has memorized the surface form of benchmark questions. When the same question is reworded — names changed, numbers swapped, phrasing restructured — the memorized pattern no longer triggers, and the model must actually reason. The performance drop directly quantifies how much of the original score was due to memorization vs. genuine capability.


Perplexity and n-gram overlap alone are insufficient. In our experiments, perplexity flagged zero samples despite strong cross-evaluation evidence of contamination — the signal is semantic, not statistical.
